# 供應商情報關係圖譜｜公開示範與安全離線檢視

此公開儲存庫僅提供互動圖譜**程式與虛構示範資料**。既有 [`index.html`](./index.html) 是虛構範例，不代表任何真實供應商、人員、價格或公司關係。

## V5 動態影響力與社群聚集（2026-11-06）

`offline-viewer.html` 已加入即時力導向物理模擬，不再固定散點：有證據的公司／法人、人物任職、設備及產品關係使用不同連線拉力，待核關係降低權重；同一演算法社群的節點自動聚集。可以拖曳節點、切換焦點、旋轉畫面、調整吸引／排斥／社群聚集與節點大小，也可以從右側調整人工關注優先級（1–5）及匯出／匯入權重設定。

節點放大權重包含資料網路中的業務關係中心性與人工優先級，**不是**企業規模、市場占有率或供應商評鑑分數。使用者明確指定的 KC、P&G、Unicharm 等重點僅在私有 V5 資料中設為較高關注級，公開工具不內嵌任何真實廠商資訊。GitHub 上的工具必須下載並以 `file://` 開啟，才可從本機選擇私有 V5 知識圖譜 JSON。V5 JSON 格式應包含 `nodes`、`edges`。

## 真正的互動式節點關係圖譜

公開的 `offline-viewer.html` 現已改為 **Canvas 網狀節點圖**，而非省份清單。可在視圖間切換「全國全景／省份網絡／人物網絡／設備與產品／聚焦關係／全部節點」，並支援節點拖曳、滾輪縮放、雙擊展開、關係線實虛線、來源檢視，以及個別廠商情報頁另存 HTML。左側省份列表是索引，不是主要圖形。

**資料隔離：** 本 GitHub 版仍不含 581 節點與 779 關係的真實資料。需要透過本機下載的 V4 JSON 載入資料後才會顯示節點；GitHub Pages 線上展示頁不開放上傳內部資料。

## 離線 V4 私有資料檢視器

[`offline-viewer.html`](./offline-viewer.html) 是不預載真實資料的離線檢視工具，用於閱讀使用者自己保存的 **V4 JSON**。支援依國家、省份篩選、搜尋公司、產品及設備、區分 V3 公司節點和新簡報名錄、顯示來源證據，以及選取單一廠商查看情報。這個工具不能代替內部資料庫的正式身分與來源驗證。

### 本機使用步驟

1. 下載 `offline-viewer.html`（從 GitHub 開啟原始檔，選擇另存）。
2. 在自己的電腦以瀏覽器開啟下載後的 HTML 檔（網址應以 `file://` 開頭）。
3. 透過頁面的「選取檔案」，手動選取已另行保存於本機的 V4 JSON 檔。
4. 依省份、廠商類別檢視；公開匹配資料、名稱地理線索與待核資料需要分開判讀。

**資料安全：** `offline-viewer.html` 不含任何實際供應商清單、實際人物資料、設備價格或商業關係。瀏覽器只讀取使用者選取的本機檔案；工具不提供伺服器上傳、遠端存取或永久儲存。當頁面不是從 `file://` 開啟時，檔案選擇會被停用，避免在公開託管頁面處理內部資料。請勿將含真實供應商資料的 V4 JSON、Excel、HTML、Markdown 或來源附件提交到此公開儲存庫。

## 資料口徑與版本

- V3 私有資料保留公司／集團、工廠／分廠、人物、設備、價格及來源等不同實體。
- V4 私有資料在 V3 上新增簡報來源名稱節點及公開補查；名稱節點不等於獨立法人。
- 「只有名稱中帶有地名」、「公開公司／營運所在地」、「已核工廠地址」不得混為一談。
- 來源的投資計畫、歷史設備規格及估計產能不可直接當成現有裝機或現場產能。
- 新增的簡報名錄不使用合作狀態欄位；如有私有資料亦須經來源核對後才可用於正式決策。

若需使用完整真實版，請由授權管理者以非公開方式取得 V4 離線資料包；公開示範倉庫不提供該資料包。
